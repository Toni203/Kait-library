\# Модуль 8. Восстановление алгоритма



\*\*Сценарий:\*\* Возврат книги библиотекарем.



\## Путь запроса



| Звено | Файл и строка | Что происходит |

| :--- | :--- | :--- |

| Интерфейс | templates/librarian.php | Кнопка «Принять» с классом return-btn и data-loan-id. |

| JS-обработчик | public/assets/js/librarian.js | Перехват клика, подтверждение, отправка запроса. |

| API-модуль | public/assets/js/api.js | Формирование POST-запроса с action=loan.return и loan\_id. |

| Сервер | public/api.php | Проверка роли, вызов LoanService. |

| Бизнес-логика | src/LoanService.php | Метод returnBook() — проверка, расчет штрафа, запись в БД. |



\## Псевдокод



Функция returnBook(loanId):

&#x20;   Прочитать выдачу из БД

&#x20;   Если выдача не найдена: Вернуть ошибку

&#x20;   Если returned\_at заполнено: Вернуть ошибку

&#x20;   Если today > due\_at И category == 'student':

&#x20;       fine = late\_days \* 15

&#x20;   Иначе: fine = 0

&#x20;   UPDATE loans, copies

&#x20;   Вернуть {ok: true, fine: fine}
