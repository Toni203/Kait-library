# Модуль 6. Сравнение браузеров и производительность

**Задача:** Выбрать браузер для отладки и ревью клиентской части проекта.

## 1. Кандидаты
1. **Google Chrome** (движок Blink).
2. **Firefox** (движок Gecko).
3. **Яндекс Браузер** (движок Blink).

## 2. Критерии и веса

| Критерий | Вес | Chrome | Firefox | Яндекс |
| :--- | :--- | :--- | :--- | :--- |
| **Инструменты разработчика (DevTools)** | 0.30 | 5 | 4 | 5 |
| **Скорость отклика (Speedometer)** | 0.25 | 5 | 4 | 5 |
| **Наличие Lighthouse для аудита** | 0.20 | 5 | 1 (нет) | 5 |
| **Совместимость с проектом** | 0.15 | 5 | 5 | 5 |
| **Потребление памяти (5 вкладок)** | 0.10 | 3 | 5 | 3 |
| **Взвешенная сумма** | **1.00** | **4.70** | **3.80** | **4.70** |

## 3. Результаты замеров
*   **Каталог проекта:** загрузился корректно во всех браузерах. В Firefox была небольшая ошибка CSS (сдвиг кнопки) — зафиксировано.
*   **Lighthouse (Chrome):** Performance = 85, Accessibility = 90, SEO = 80.
*   **Cookie (PHPSESSID):** во всех браузерах флаг HttpOnly не установлен, Secure отсутствует. (Находка для Модуля 10).
*   **TTFB (каталог):** Chrome — 120 мс, Firefox — 125 мс, Яндекс — 120 мс.

## 4. Вывод
Выбраны **Chrome** и **Яндекс Браузер** (по 4.70 балла), так как они имеют одинаковый движок Blink, мощные DevTools и встроенный Lighthouse. Firefox рекомендован как дополнительный браузер для кросс-браузерного тестирования (движок Gecko).
