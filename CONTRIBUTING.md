# Инструкция для разработчиков (CONTRIBUTING)

## 1. Что установить
Для работы над проектом вам понадобятся:
* Веб-сервер XAMPP (Apache + MySQL).
* Редактор кода VS Code с расширениями: PHP Intelephense, EditorConfig for VS Code.
* Система контроля версий Git.

## 2. Как запустить проект с нуля
1. Склонируйте репозиторий.
2. Скопируйте файл .env.example в .env.
3. Создайте базу данных kait_library.
4. Импортируйте database/schema.sql и database/seed.sql.
5. Запустите Apache и MySQL в XAMPP.
6. Откройте в браузере http://localhost/kait-library-main/public/.

## 3. Настройки редактора
В проекте есть файл .editorconfig. Он автоматически задает правила: кодировка UTF-8, отступы пробелами (4 шт.), окончания строк LF. Не меняйте эти настройки вручную.

## 4. Как проверять стиль кода
Мы используем стандарт PSR-12 и линтер PHP_CodeSniffer.
Перед коммитом проверьте код: C:\xampp\php\php.exe phpcs.phar --report=summary
Если есть ошибки, исправьте их автоматически: C:\xampp\php\php.exe phpcbf.phar

## 5. Правила веток и коммитов
* Новая задача = новая ветка (например, practice/m04).
* Коммиты должны быть осмысленными (например, style: исправлены отступы).
* Автоформатирование (phpcbf) коммитится отдельно от изменений логики!

## 6. Чего НЕ коммитить
* Папку vendor/ или node_modules/.
* Личные настройки IDE (например, .idea/).
* Файл .env (там могут быть пароли).
